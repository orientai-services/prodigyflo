What to reflect on

Honest state of the MVP

"Shipped" is accurate but not the whole story. These are the areas where the MVP is deliberately provisional, and what each one waits on.

Real send adapters are in — credentials switch them on

Resend (email) and Twilio (SMS) adapters now ship behind the same interfaces; the default remains the labelled mock until EMAIL_PROVIDER=resend / SMS_PROVIDER=twilio plus keys are set — in env or in each connector's encrypted credential vault (Settings → Connectors, password step-up gated). Sheets sync remains mock-only.

The CYS field map is an informed guess

The starter map covers a solar-cancellation handover, but it has not been reconciled against the CYS portal's real intake fields. Because the map is configuration — edited in Settings, no deploy — reconciling it is a 30-minute session with someone who has portal access, and it should happen before the first real handover.

Demo accounts deactivated in production

The 2026-08-28 agency migration deactivated all 33 seeded demo logins. Active accounts are now only the real agency users plus the Lead Recovery investor demo (confined to its own view). The seed still creates demo accounts for local development, where they belong.

Photographed documents: vision OCR wired, keyed off Anthropic

JPEG/PNG/WebP uploads now travel to the Anthropic extractor as image content under the same provenance contract (values literally visible, confidence, exact snippet; fields land unverified for human review). With AI_PROVIDER=mock the system still honestly refuses to read photos; HEIC keeps the no-OCR warning.

AI extraction runs in mock mode by default

AI_PROVIDER=mock ships deterministic extraction so the review workflow is testable and free. The Anthropic provider is already implemented — switching it on is a config change plus API spend, and every AI value still requires human verification either way.

Production is real-data-only now

The agency migration purged all 250 synthetic clients (full backups kept) — production holds only what real connectors deliver. The caveat inverts: the workflow still hasn't met real-world messiness at volume — odd phone formats, half-filled forms, blurry uploads. Expect a tuning pass as the GHL import and live intake land.

Multi-tenant by construction, single-tenant by experience

Every query is scoped through one visibility rule and cross-organization isolation is covered by tests — but only one organization has ever lived in the database. A second company onboarding would be the real test.
