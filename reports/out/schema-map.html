Schema invariants (7)

Webhook idempotency

IntakeSubmission is unique on (sourceId, externalId) — a replayed form post updates one row and can never create a second lead.

Human gate on AI output

ExtractedField.verification starts UNVERIFIED; downstream CYS resolution can raise it to SUGGESTED at most. Only a person makes a value VERIFIED.

Append-only audit

AuditEvent rows are inserted, never updated or deleted, with actor, redacted before/after, and hashed IP.

Tenant scoping

Every scoped model carries organizationId, and a single visibility rule (clientScope()) is spread into every Client query — never hand-filtered.

Document version chain

A re-upload creates version N+1 with supersedesId set. Files live under opaque keys and are served only through signed, permission-checked routes.

Hub models

Client and User are the gravity wells of the graph — most chords land on them. Any migration touching either deserves extra review.

Soft deletes only at the core

deletedAt exists on Organization, User, Client; child rows rely on cascades. Retention policy for documents is a setting, not yet a job.
